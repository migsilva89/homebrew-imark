# Homebrew tap for Imark

[Imark](https://github.com/migsilva89/imark) is a native macOS Markdown reader
that keeps your comments inside the `.md` file itself.

```bash
brew install --cask migsilva89/imark/imark
```

Upgrading later:

```bash
brew upgrade --cask imark
```

The cask points at the signed, notarised DMG attached to each GitHub release.
